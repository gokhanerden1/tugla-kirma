# Tuğla Kırma Oyunu 🎮

C# ve Nesne Yönelimli Programlama (OOP) prensipleri kullanılarak geliştirilmiş, dinamik oyun mekaniklerine sahip klasik bir tuğla kırma oyunu projesidir.

## 🛠️ Kullanılan Teknolojiler
- **Dil:** C#
- **Platform:** .NET Windows Forms / Console

## 🚀 Proje Özellikleri
- Nesne yönelimli mimari (Kullanıcı, Top, Tuğlalar ayrı sınıflar olarak tasarlanmıştır).
- Dinamik çarpışma testleri ve skor takibi.
- Okunabilir ve sürdürülebilir temiz kod (Clean Code) yapısı.
